# TradeGuard — Real-Time Fraud Detection Platform

TradeGuard is a full-stack platform for real-time fraud detection, transaction scoring, and analyst investigation workflows.

## Tech Stack

- Frontend: React + TypeScript + Tailwind
- Backend: FastAPI (Python)
- Ingestion: Kafka
- Processing: PySpark
- ML: Scikit-learn / PyTorch
- Database: PostgreSQL
- Infra: Docker, GitHub Actions CI/CD
